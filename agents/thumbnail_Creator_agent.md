# DevMantra Thumbnail Creator Prompt

Use this prompt in any AI image generation tool (ChatGPT, Midjourney, Firefly, etc.)

---

## Base Prompt Template

```
Create a professional blog/newsletter thumbnail image.

Topic: [YOUR TOPIC HERE]
Style: Clean, modern, tech/business editorial
Background: Dark navy blue (#001D30) or deep gradient
Text overlay: Bold headline "[YOUR TITLE]" — large, white, high contrast
Sub-label: "DevMantra" small badge or watermark bottom-right
Visual element: [relevant icon / illustration / abstract graphic related to topic]

Layout rules:
- Safe zone: keep all text and key visuals within the center 80% of the canvas
- Left or right 10% may be cropped on mobile — avoid placing critical content there
- Minimum font size for any text: 48px equivalent
- Padding from edges: at least 60px on all sides

Output: 1280×720px, 16:9 aspect ratio, RGB, high resolution
```

---

## Usage Notes

- **Recommended output size:** 1280×720px (true 16:9)
- **Safe text zone:** center 80% of canvas (128px margin left/right)
- **Brand color:** `#001D30` (dark navy) as primary background
- **Font style:** Bold, sans-serif, white — high contrast against dark background
- Replace `[YOUR TOPIC HERE]` with the article/newsletter subject
- Replace `[YOUR TITLE]` with the exact headline you want on the image
- Replace `[relevant icon...]` with a description of the visual (e.g. "AI robot icon", "stock chart graphic", "globe with data lines")
